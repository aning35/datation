# Auto Form Filling SOP

当用户的任务是"表单填充"类型时，执行层 **必须** 按以下核心步骤紧凑执行：

## Step 1: 解析目标模板
- 读取目标表单/模板文件，提取出需要填写的 **所有字段名**（占位符）及 **表格/列表结构**。
- 输出：一份简明的字段清单。

## Step 2: 数据匹配与填充
- 读取源数据（用户消息中的数据或上传的数据文件），在源数据中逐一查找与目标字段对应的值。
- **直接做字符串替换**：将模板中的占位符逐个替换为实际值。
- 如果某些字段的值需要经过计算/聚合才能得到（如求和、统计、公式推导等），则在本步骤中直接执行计算。
- 枚举字段严格匹配允许值；缺失数据保留原占位符或填 `null`。

## Step 3: 输出最终文件
- 将填充完成的文本保存为新文件（如 `xxx_filled.txt`），输出到 `outputs/` 目录。
- 如果是 JSON Schema 类型的表单，则输出严格符合 Schema 的 JSON，用 ```json ... ``` 包裹。

## 严格禁令
- **禁止** 对填充结果进行"合规性审查"、"法律分析"、"校验报告"等额外工作。表单填充的职责是 **忠实地将数据填入模板**，不做任何超出范围的分析。
- **禁止** 将核心流程拆分成碎片子步骤（如分别读文件、分别分析 schema、逐字段校验等都是不必要的拆分）。
- Planner 以上述 3 个步骤为骨架。如果数据需要额外的计算或转换，可以在 Step 2 中内联处理或额外插入 1 个计算步骤，但绝不能膨胀为 5 步以上。
